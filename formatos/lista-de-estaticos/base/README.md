# Motor da lista de estáticos

`render_lista.py --pasta <sandbox> [--storyboard | --out <mp4> | --conferir --out <mp4>]`. A pasta tem `cenas.json` (ver `cenas-modelo.json`: video, titulo, itens com nome/imagem/t, cortes, fim) e as imagens. Lado da lista pelo rosto (OpenCV). Análise da fala: `app/ferramentas/analisar_fala.py`.
